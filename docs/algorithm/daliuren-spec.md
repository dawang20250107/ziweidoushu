## 2. 天地盘

月将加于占时之上,顺行:`tp[i] = (月将 + (i − 占时)) mod 12`。
即地盘占时位乘月将,余位顺推。伏吟 `tp[i]==i`、返吟 `tp[i]==(i+6)%12`。

## 3. 四课

- 第一课:日干寄宫为下神,其上神(`tp[寄宫]`)为上神;
- 第二课:第一课上神为下神,其上神为上神;
- 第三课:日支为下神,其上神为上神;
- 第四课:第三课上神为下神,其上神为上神。

## 4. 九宗门三传(理法易简简化口径)

**发用检测序**:伏吟/返吟(天地盘特征)→ 贼克 → 比用 → 涉害 → 遥克 → 昴星。
克关系:下贼上(下克上)**优先于**上克下;有下贼上则弃全部上克下。
第一课之「下」为**日干本身,以本气五行论克**(寄宫仅定其地盘座位)——
《六壬断案》案02(戊申日子将申时)钉死:戊土上酉金无克,方成元首取辰;
若误以寄宫巳火论则巳克酉成重审,与书相悖。

**重课规则**:派生课(第二/第四课)与前课下上全同者**不取其克**
(「干支阴阳已先据其位,不可重复取用」,断案案07 钉死);干支两正课
(第一/第三课)不在此限——八专日课一课三支面同而克义异
(课经「癸丑日俱有克」,案220 钉死)。

| 门 | 条件与取用 |
|---|---|
| 贼克 | 唯一克 → 初传取该上神 |
| 比用 | 多克 → 取上神阴阳**同日干**者(唯一时) |
| 涉害 | 比用不决 → 俱比者于**比者之中**取、俱不比于全体候选取;**孟>仲>季>课序**,孟仲季论上神所临之**地盘位**(理法易简「不数深浅先取孟上神」之见机式)。断案五例钉死:案76(午临亥孟)、案74(午临申孟)、案188(无孟取仲:未临卯仲)、案189(戌临寅孟)、案191(丑临卯仲)。曾试「历位数克」深浅法,与诸案不合而弃 |
| 八专 | 干支同位(甲寅/庚申/丁未/己未/癸丑)无贼克,**不论遥克** → 刚日干上神顺数三位、柔日第四课上神逆数三位;中末俱并干上(课经走例:甲寅日辰时丑将→丑亥亥、丁未日丑时辰将→亥戌戌) |
| 遥克 | 四课无克 → 二三四课上神与日干(本气五行)隔位相克;**先取克干者(蒿矢)**,无则干克者(弹射),再比用取舍(断案案36/案95「蒿矢」钉死) |
| 别责 | 无克无遥且**三课备**(四课不全)→ 刚日取干合之干寄宫上神、柔日取日支三合前一辰(支+4);中末俱并干上(课经走例:丙辰日卯时辰将→亥午午) |
| 昴星 | 无克无遥、四课全备 → 阳日取地盘酉上之天盘(中支上、末干上),阴日取天盘酉临之地盘(中干上、末支上)——刚仰柔俯 |
| 伏吟 | 将=时;有克取克,无克刚日取干上、柔日取支上;中传=初传之刑,**初传自刑者阳日中取支上、阴日中取干上**;中传复自刑者末传冲取(断案案215 辛酉日丑将丑时钉死:酉戌未) |
| 返吟 | 将冲时;有克取克,无克取**驿马**发用,中支上、末干上 |

**中末通式**(伏吟/八专/别责除外):中传=初传之上神、末传=中传之上神(顺天盘)。

**旬空/遁干**:旬首(甲)所临支 = 日支-日干;旬内十支带旬遁干
(`chuanDunGan`,如己卯日三传巳戌卯遁辛/甲/己),旬外二支即空亡
(`xunKong`);传落空亡遁干为空,断语层记「落空亡」减分。

**占时两制**:正时(`CastByTime`,以当下时辰——同一时辰之课人人相同,
古法本然,断案诸例皆正时,以年命分断)与**活时报数**
(`CastByTimeBaoShu`,自子顺数报数所至之支 `(n-1)%12` 为占时,
日干支/月将仍按实时;`baoShu`/`hourNote` 溯源随课回传,AI 解课与
卦档以同数重推同课)。产品层默认报数活时(留空由服务端 crypto 代摇
1-12),众人同刻各得其课。
