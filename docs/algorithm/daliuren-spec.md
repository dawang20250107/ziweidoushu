## 2. 天地盘

月将加于占时之上,顺行:`tp[i] = (月将 + (i − 占时)) mod 12`。
即地盘占时位乘月将,余位顺推。伏吟 `tp[i]==i`、返吟 `tp[i]==(i+6)%12`。

## 3. 四课

- 第二课:第一课上神为下神,其上神为上神;
- 第三课:日支为下神,其上神为上神;
- 第四课:第三课上神为下神,其上神为上神。

## 4. 九宗门三传(理法易简简化口径)

**发用检测序**:伏吟/返吟(天地盘特征)→ 贼克 → 比用 → 涉害 → 遥克 → 昴星。
克关系:下贼上(下克上)**优先于**上克下;有下贼上则弃全部上克下。
第一课之「下」为**日干本身,以本气五行论克**(寄宫仅定其地盘座位)——
《六壬断案》案02(戊申日子将申时)钉死:戊土上酉金无克,方成元首取辰;
若误以寄宫巳火论则巳克酉成重审,与书相悖。

| 门 | 条件与取用 |
|---|---|
| 贼克 | 唯一克 → 初传取该上神 |
| 比用 | 多克 → 取上神阴阳**同日干**者(唯一时) |
| 涉害 | 比用不决 → 俱比者于**比者之中**取、俱不比于全体候选取;**孟>仲>季>课序**,孟仲季论上神所临之**地盘位**(见机式「孟上神」,断案案76 钉死:午临地盘亥孟位发用),不数实际涉害深浅 |
| 遥克 | 四课无克 → 日干(本气五行)与上神相克者发用 |
| 昴星 | 无克无遥 → 阳日取地盘酉上之天盘(中支上、末干上),阴日取天盘酉临之地盘(中干上、末支上)——刚仰柔俯 |
| 伏吟 | 将=时;有克取克,无克刚日取干上、柔日取支上;**中末用刑**,自刑取冲 |
| 返吟 | 将冲时;有克取克,无克取**驿马**发用,中支上、末干上 |

**中末通式**(伏吟除外):中传=初传之上神、末传=中传之上神(顺天盘)。
