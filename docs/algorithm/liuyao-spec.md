## 1. 装卦(assemble)

1. **纳甲**:京房八宫纳干支表(`najia`),内外卦各取所纳三支;
   乾纳甲/壬、坤纳乙/癸(内外异干),余卦内外同干。
2. **宫属与世应**:八宫六十四卦按变爻规律生成(纯卦→一至五世变初~五爻
   →游魂再变四爻→归魂内卦复原),预建 `palaceIndex`;世位
   `[6,1,2,3,4,5,4,3]`(按宫内序),应=世±3。与《卜筮正宗》定表 64 卦
   逐卦对照(TestBaGongTable)。
3. **六亲**:宫五行 vs 爻支五行——同我兄弟/我生子孙/我克妻财/克我官鬼/
   生我父母。**变爻六亲仍以本宫五行论**;变爻纳甲按变卦自身内外卦纳。
4. **六神**:日干起初爻——甲乙青龙、丙丁朱雀、戊勾陈、己腾蛇、庚辛白虎、
   壬癸玄武,顺行六位。
5. **摇卦映射**:背面数 1=少阳、2=少阴、3=老阳动、0=老阴动;
   服务端摇卦用 crypto/rand。

## 4. 取用层

1. **用神建议**(`yongShen`):问题文本事类→六亲映射,**人物优先于事类**
   (「儿子考试」取子孙);无归类默认世爻。仅建议,AI 可按事理改取。
2. **元忌仇链**:六亲相生环(父母→兄弟→子孙→妻财→官鬼→)逆推:
   生用者**元**,生元者(恰克用)**忌**,生忌者(恰克元)**仇**;
   世爻用神按所临六亲推链。输出三神名与元/忌爻位。
3. **力量评估**(`yuanShenPower`/`jiShenPower`):增删有力/无力条目
   机械对照(动含暗动;**动墓限明动**;忌与元同动=贪生忘克无力);
   冲突保守取无力附另见。总纲:总贵用神有气。

## 4.5 补强层(enrich.go,《六爻玄奇》查漏定题、增删/正宗口径落地)

1. **卦性**(`benXingZhi`/`bianXingZhi`):三对爻(初四/二五/三上)支支
   相冲=六冲卦、相合=六合卦;冲主散、合主成,冲合互变先后有别;
2. **伏神之法**(`fuShen`):用神不上卦时从**本宫首卦纳甲**取伏
   (自下而上首位),飞神=本卦同位爻;出伏判定序:飞空自出 > 日冲飞开 >
   飞来生伏 > 伏得月旺相 > 伏得日生扶 > 飞克伏难出 > 伏空难出;
   出伏应期=值伏神或冲飞神之日;
3. **六神事象**:静表六神→事象修饰,只入断语不入吉凶分;
4. **应期具体地支**:静应值冲、动应值合、空应冲空填实、破应合破、
   墓应冲开墓库(冲墓支)、绝应逢生(长生支);
5. **爻位象义 + 内外远近**:初足宅基…上头顶远末;内卦近速、外卦远缓;
6. **动爻对用神**:合绊(应待冲开)/冲动(旺相冲起、休囚冲散);
7. **三合局**:动爻(明/暗动)二支 + 日月建补一字(虚一待用)成局,
   局五行对用神论生克;
8. **游魂/归魂**、**世空/应空**专断。
