# 产品与技术路线图(v1,已拍板)

> 定位:基于倪海厦《天纪》体系的 AI+ 紫微斗数平台。
> 产品标准:科技风格、对标硅谷顶尖 SaaS、深度移动端适配、面向市场的顶尖产品级别。

## 已拍板的技术决策

| 决策项 | 结论 | 核心理由 |
|--------|------|----------|
| 后端 | Go(已完成重构) | 高并发原生、单二进制部署、lunar-go 历法与基准同源 |
| 前端 | **Next.js 15 + React 19 + TypeScript + Tailwind CSS 4 + shadcn/ui + Framer Motion** | 顶级 SaaS 设计生态、SSR 利于 SEO、自建设计系统 |
| 小程序 | **Taro(React 语法)** | 与 Web 共享 TS 类型、API client、设计 token |
| 数据库 | **PostgreSQL 16(唯一事实源)+ Redis 7(共享态)** | 支付事务、JSONB 命盘快照、pgvector 做 RAG;Redis 做限流/会话/队列 |
| 古籍语料 | 保持内存快照 + 二元索引(不入库) | 读多写少,现有方案即最优 |
| 代码组织 | **Monorepo**:根为 Go API,新增 `web/`(Next.js)与 `miniapp/`(Taro) | 类型契约同仓同步,一处审查 |
| 目标市场 | **先国内** | 手机号+微信登录;微信/支付宝支付;海外(Stripe/多语言)二期开关预留 |

## 产品矩阵(围绕客户粘性)

粘性三支柱:**高频回访理由 + 数据锁定 + 关系链**。

### 引流层(免费,获客与 SEO)
- 排盘工作台(星盘视觉 = 产品记忆点)
- 基础格局判定、古籍阅读与全文检索
- 主星×主题知识页(SEO 静态页矩阵)
- 命盘分享卡片

### 粘性层(回访与锁定)
- **每日运势**:流年流月流日四化的个人化日签 + 小程序订阅消息推送(习惯回路)
- **AI 命理对话**:记住命盘与历史对话的持续咨询(AI+ 差异化本体)
- **命盘档案库**:保存家人朋友命盘(数据锁定)
- **合盘**:恋爱/合伙契合度(双人传播、关系链)
- **生命周期提醒**:大限交接、流年化忌入命等事件推送

### 变现层(订阅)
- 年度运势报告(春节 = 天然续费节点)
- 深度主题报告(事业/婚恋/健康)
- 倪师体系精读:天纪课程学习路径 + 古籍逐段倪师注解(内容护城河,待资料到位)

### 会员分层
| 层级 | 内容 |
|------|------|
| 免费 | 排盘、基础格局、古籍检索、有限 AI 解读(免费层必须好用——获客靠它) |
| Pro 订阅 | AI 无限对话、每日运势、合盘、档案无限、年度报告 |
| 大师版 | 更强模型、专属深度报告、(预留)真人咨询对接 |

## 注册 / 支付(国内口径)

- **注册登录**:手机号+短信验证码为主;微信登录(Web 扫码 + 小程序原生),UnionID 打通两端身份;JWT 双 token + Redis 会话版本控制
- **支付**:微信支付(小程序 JSAPI + Web Native)、支付宝(Web/H5);订阅为**周期购买制**(1/3/12 月)+ 到期提醒,不做自动扣款;订单状态机 + webhook 幂等 + 每日对账
- 海外:Stripe / Apple / Google 登录,二期以 feature flag 预留

## 平台必备(补充项)

1. **管理后台**:内容/用户/订单管理、AI 成本看板(同 Next.js 栈)
2. **合规**:命理内容定位「传统文化/娱乐参考」+ 全站免责声明;出生数据按 PIPL 保护;支付主体资质
3. **观测与 CI/CD**:GitHub Actions 测试门禁(黄金基准回归全绿才可合并)、Sentry、Prometheus/Grafana
4. **AI 成本治理**:按会员层级路由模型 + 解读缓存 + 每用户配额

## 分阶段执行(协作模式:Fable 5 架构/关键实现/验收,Opus 4.8 执行)

| 阶段 | 交付 | 关键活(Fable 亲自) | 执行活(Opus) |
|------|------|---------------------|---------------|
| P0 | 设计系统、DB Schema、鉴权/支付架构设计 | 全部(不可逆决策) | — |
| P1 MVP | Web 排盘工作台、注册登录、AI 对话、订阅+支付 | 支付状态机、鉴权、星盘核心组件 | 页面批量实现、组件库、测试 |
| P2 | 每日运势、档案库、合盘、小程序(Taro) | 推送架构、UnionID 身份打通 | 小程序页面、报告模板 |
| P3 | 古籍精读、年度报告、增长(邀请/裂变) | 语料质量验收 | 内容批量结构化 |

**执行纪律**:任务派发前先立机器可验收标准(测试/契约/基准);出错不可逆或影响全局的由 Fable 亲自做;委派产出至少过一道独立校验。
