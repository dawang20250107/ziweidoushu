## 3. 我们已经领先的地方(护城河,须持续放大)

1. **正确性可证**:净室引擎 + **两套彼此独立的黄金基准**(iztro 1566 例 + zwds 结构表 800+ 格)逐格验证,还反向查出竞品数据错误。竞品是黑箱静态表,无法自证正确——这是**别人拿不走**的信任资产。
2. **AI 解读 + 古籍引用**:竞品多为固定断语;我方 LLM 解读 + 倪师体系/公版古籍内部检索引用,深度与可解释性代际领先。
3. **顶级科技美学 + 深度移动端**:竞品多为老式桌面/工具 UI;我方观星台视觉 + 全站移动适配。
4. **跨端云档 + 研读一体**:排盘—问卦—卦档—古籍研读闭环。

结论:**我们不靠「系统更多」取胜,靠「同样的系统,排得更对、解得更深、体验更好」**。路线据此排优先级。

## 4. 缺口清单 + 优先级(对齐天纪 + 深度定位)

### T1 — 天纪核心 · 高价值 · 优先做深做透
1. **八字(子平)成独立产品级视图**:现为视角层。补**大运排布/起运/流年/小运** + 用神喜忌 + AI 断语(引穷通宝鉴/子平真诠公版)。消费级最高频,且与紫微同源数据,增量小、回报大。
2. **大六壬完成第二步**:天将(贵人昼夜十二将)/神煞/毕法要诀/断课。已有起课骨架,补齐即成三式之一完整体。
3. **择日(天星/协纪辨方)**:天纪核心,现为空白。事项(嫁娶/开市/动土/安葬…)× 日课吉凶 + 神煞宜忌。以《协纪辨方书》公版为纲。
4. **六爻/梅花断卦深化**:引擎已足;深化 AI 断卦(用神取舍已有)、卦爻辞公版接入。

### T2 — 广度补强 · 平台完整度 · 消费级拉新
5. **姓名学(五格剖象+三才+生肖)**:引擎极轻、消费级极高频,适合做**引流/低价按次**。规则公开(熊崎氏五格),自研即可。
6. **黄历/万年历基座**:节气/真太阳时/每日宜忌神煞(**非「每日运势」**,是通用工具)。可复用现有历法能力,夯实全站时间基座。
7. **奇门遁甲**:三式之一、热度高。排局(阳遁阴遁/转盘飞盘)+ 九星八门八神。引擎较重,列 T2 尾。

### T3 — 暂缓/不做(偏离定位或需特殊输入)
- 太乙神数、河洛理数(小众);相术(需影像);西洋占星(非本土体系,离天纪远);阳宅玄空(需户型/罗盘,重,后置)。

## 5. 补齐与超越路线(分批,全净室)

> 每一项都遵循我方成熟范式:**先跨书/公开规则确证 → 建黄金基准 → 引擎实现 →
> 回归钉死 → AI 断语引公版古籍 → 前端呈现**。断语一律自研或公版,绝不第三方。

**批次 A(命理深度,增量最小回报最大)**
- A1 八字大运/流年/起运 + 用神喜忌 → 四柱视角升为「八字盘」子页(仍与紫微同源)。
- A2 六爻/梅花断卦 AI 深化 + 卦爻辞(公版《周易》)接入阅读引用。

**批次 B(天纪补全)**
- B1 大六壬第二步:天将/神煞/毕法/断课(接已有起课骨架)。
- B2 择日引擎:协纪辨方神煞体系 + 事项宜忌 + 日课评分;黄历基座(B 前置或并行)。

**批次 C(广度与拉新)**
- C1 姓名学(五格三才生肖)——轻引擎、低价按次引流。
- C2 黄历/万年历工具页(节气/真太阳时/宜忌)。
- C3 奇门遁甲排局(视资源)。

**贯穿(护城河放大)**
- 每个新体系都配**独立黄金基准 + 回归**(延续 iztro/zwds「以机校机」范式),把「排得对」做成全行业最强、且可对外证明的卖点。
- AI 解读统一走「公版古籍/原创」引用,深度拉开与静态断语竞品的差距。
