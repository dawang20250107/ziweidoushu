# 多维断语架构:确定性骨架 + AI 行文

## 问题

不同人的排盘,前端断语雷同、「没个准头」。根因:无 LLM Key 时走的规则化降级
只是「命宫主星关键词罗列 + 格局 + 一句通用大限」,**没有把本盘的具体星曜组合
拿来断**——只看命宫、且是单星关键词,故两张不同盘塌缩成几乎相同的输出。

## 方案:确定性多维断语骨架

`internal/ai/reading.go` `buildReading(chart, patterns)` → `Reading{Overview, Sections[]}`。
每个维度(**十二宫 + 当前大限**)的断语是**本盘该宫的函数**:

```
断语(宫) = f(该宫主星, 庙旺档, 生年四化, 同宫/会照煞星, 会照吉星, 宫位领域)
```

- **主星**:十四主星各有 {核心, 得地正面, 落陷负面} 三态,按庙旺取用。
- **四化**:化禄/权/科 加分、化忌减分,点睛入断。
- **煞吉**:同宫/会照煞星→波折;吉星→助力。
- **宫位透镜**:同一颗星在财帛/官禄/夫妻读法不同(领域框定)。
- **吉凶档**:按上述加权打分 → good/caution/neutral。

因输出是「星曜 × 庙旺 × 四化 × 煞吉」的组合,**两张不同盘必得显著不同的逐宫断语**
(回归 `reading_test.go`:两盘断语雷同度 < 25%,命宫断语必引本盘命宫主星)。

## 分层与接入

1. **确定性骨架恒在**:`/api/v1/chart` 响应内含 `reading`(不走 LLM、零成本、始终可用),
   前端 `ReadingPanel` 渲染为「命格总论 + 十二维度切换」卡片。这是「准头」底座。
2. **无 Key 降级**:`fallbackText` 直接渲染骨架为 Markdown(多维、随盘异),不再是关键词罗列。
3. **有 Key 深度**:骨架作为「逐宫判定骨架(须据此贴盘,不得写通用套话)」注入 LLM 提示词,
   令 LLM 行文也贴盘,而非通用套话——同一根因两处堵死。

## 内容边界

断语文本为**我方原创 + 公版紫微通则**,不含任何第三方软件断语。星曜三态、宫位透镜
均可依《紫微斗数全书》等公版独立校订与扩充。

## 已深化(准头层)

- **三方四正合参**(对宫+三合)已进命宫/大限综论与逐宫;
- **双主星同宫组合专断**:24 组(紫破/武贪/廉杀…)公版星系通则原创提炼,
  同宫两主星自成一格,非特质相加——`starPairTrait` + `pairTraitOf`;
- **生年四化落宫串联**:禄权科忌各自定位到宫,串一生福泽与罣碍;
  化忌冲对宫、禄忌交战一并点出——`sectionForSihua`;
- **流年维度断语**:以 `ReferenceYear` 为当年,流年命宫落于本命何宫定本年主题,
  流年四化飞入本命何宫定本年动向;与大限十年、本命一生分层合看——`sectionForLiuNian`;
- **真太阳时国际化**:出生地经度 + 时区标准经线(48 世界城市 + 335 国内城市),
  前端 `TrueSolarPicker` 打通端到端。

- **宫位透镜按星细化(14×12)**:同一主星落于不同宫读法迥异(太阴在财帛主积财、
  在夫妻主配偶柔美),168 条「星×宫」专属断语,逐宫优先取用、缺项回退通用星性
  ——`starPalaceTrait` / `starInPalace`(`reading_starpalace.go`)。

- **运限逐层断语**:`/api/v1/horoscope` 随运限返回 `reading`,大限→流年→流月→
  流日→流时逐层贴盘:每层命宫落本命何宫定时段主轴,流曜(流禄/流羊/流马/流鸾…)
  会照三方四正添吉助或增波折,流年层另叠流年四化飞本命;流月/流日/流时的宫干
  四化属飞星派,仅附注不作定断(与引擎口径一致)——`buildHoroscopeReading`
  (`horoscope_reading.go`),前端 `HoroscopeReadingPanel` 随时间轴呈现。

- **应验分档**:主星组合再叠煞吉会照,从「格性」推进到「应验档位」——贪狼逢
  火铃→暴发格,廉杀逢羊陀→『路上埋尸』血光档,杀破逢煞→冲击档,巨门逢煞忌→
  是非档,空劫会财星→成空档,日月落陷化忌→损耗档;会昌曲→文贵档,财星会禄存→
  财禄档。以本宫+三方四正会照为触发,并计入吉凶评分——`escalations`
  (`reading_escalation.go`)。
- **运限触发本命格局**:大限/流年/流月/流日/流时命宫行至参与本命格局的宫位,
  该格局于本时段「引动、显发、为应期」,吉格宜顺势、凶格宜预化——`patternsAtPalace`
  织入运限逐层断语。

至此本命 15 维(生年四化 + 十二宫 + 大限 + 流年)+ 运限 5 层逐时段断语。
逐宫断语层层复合:星×宫专属 → 双星组合 → 应验分档 → 生年四化 → 煞吉会照 →
三方四正 → 综论;运限层另叠「引动本命格局」应期判定。

- **应验分档同宫/会照分力**:煞吉贴身(同宫)力足、隔位(三方会照)力缓,
  古法轻重有别——`aspect`/`aspectOf` 区分并分档计分。
- **合盘确定性断语**:`/api/v1/heming` 随响应返回 `reading`,比对双盘三信号——
  年命相合(六合/三合/相冲/刑/害)、四化互飞(生年四化飞入对方命宫/夫妻宫,禄科
  情深、忌则牵绊)、夫妻宫呼应(一方夫妻宫应对方命宫)——加权成 20-100 契合分 +
  分向断语 + 相处建议;`buildHemingReading`(`heming_reading.go`),前端
  `HemingReadingPanel` 契合度环呈现。
