# 观星台设计系统(P0 定稿)

> 视觉命题:**一座现代观星台**——仪器般精密的科技感,承载紫微垣的星空与古籍的纸墨。
> 不是通用暗色 SaaS 模板:所有色彩与形制从紫微斗数自己的世界取材。
> Token 唯一来源:[tokens.css](./tokens.css)。组件禁止硬编码色值/字号/间距。

## 1. 双主题的分工

| 主题 | 场景 | 底色逻辑 |
|------|------|----------|
| **玄穹**(dark,默认) | 排盘工作台、运限时间轴、AI 对话 | 偏靛夜空黑 `#0e1220`(紫微垣即北天极星区,靛而非纯黑);层级靠 1px 边线 + 金晕,不堆投影 |
| **宣纸**(light) | 古籍阅读器、知识页、报告 | 暖纸底 `#f5f0e4` + 青墨 `#2a2c35`——古籍就该在纸上读 |

跟随系统偏好,手动切换用 `data-theme` 覆盖(token 级覆盖,双向都生效)。
两主题各自独立调校对比度,不做简单反色。

## 2. 色彩:一个强调色 + 两套领域语义

**星曜金 `--gold` 是唯一强调色**(按钮/链接/选中/焦点)。垣紫 `--violet` 只做氛围
(浮层微染、装饰线),永不用于交互——克制是科技感的来源,金紫渐变是明令禁止项。

产品独有的两套**领域语义色阶**(通用产品没有,这是我们的视觉指纹):

- **庙旺利陷五阶**(星曜亮度):庙=辉金 → 旺=曜金 → 得利平=星灰 → 不=晦 → 陷=沉。
  星盘上一眼读出星曜强弱,不靠文字标注。
- **四化四色**:禄=翠 `#57b583`、权=赭 `#d08a3e`、科=青 `#5e8fc7`、忌=朱 `#c7554f`。
  以「标记徽章」形式挂在星曜右上,不给星名本身染色(保持星名可读性)。

系统语义色(成功/警告/危险/信息)与四化共用色相但**用途严格分离**:
四化徽章永远带「化」字形制,系统状态永远是条/点/toast,不混淆。

## 3. 字体:三副面孔

| 角色 | 字体栈 | 用在哪 |
|------|--------|--------|
| 陈述(display) | 思源宋体 Noto Serif SC | 大标题、宫名、格局名、星盘中宫——仪式感 |
| 界面(body) | 系统黑体栈(PingFang/MiSans/HarmonyOS/Noto Sans SC) | 一切 UI 文本——不加载即最快 |
| 古籍(reading) | 霞鹜文楷 LXGW WenKai(自托管子集) | 古籍正文、倪师语录、引文——纸墨气质 |

**加载策略**(中文字体体积巨大,这是工程约束):UI 走系统栈零加载;
思源宋体与霞鹜文楷按页面实际用字**构建期子集化**(cn-font-split),
`font-display: swap`,古籍阅读器预加载当前书的字体分片。
数字一律 `font-variant-numeric: tabular-nums`(四柱、年份、价格对齐)。

正文栏宽 `68ch`;古籍行高 1.9、UI 行高 1.6;小标签字距 `0.08em`。

## 4. 形制与动效

- **近方的克制圆角**:徽章 2px、卡片 6px、弹窗 10px——仪器感,不做全圆角软糖
- 间距 8px 基数阶;星盘宫格最小 132px
- **动效只花在一处**:星盘。入场时十二宫按安星顺序 420ms 级联点亮(`--ease-out`),
  宫位聚焦时三方四正连线渐显;其余交互一律 120/200ms 的朴素过渡。
  `prefers-reduced-motion` 时全部动效归零(token 已内置)
- 焦点可见:双层焦点环(底色 2px + 金 2px),键盘可完整操作星盘

## 5. 星盘规格(核心组件契约)

```
┌────┬────┬────┬────┐   4×4 网格:外环十二宫,
│ 巳 │ 午 │ 未 │ 申 │   中央 2×2 为中宫(命主信息:
├────┼────┴────┼────┤   姓名/四柱/五行局/命主身主)。
│ 辰 │         │ 酉 │
├────┤  中宫    ├────┤   宫格布局(地支固定位):
│ 卯 │         │ 戌 │   巳午未申 / 辰(中)酉 /
├────┼────┬────┼────┤   卯(中)戌 / 寅丑子亥
│ 寅 │ 丑 │ 子 │ 亥 │
└────┴────┴────┴────┘
```

**宫格解剖**(自上而下):主星行(宋体 + 亮度色 + 四化徽章)→ 辅星行 →
杂曜行(可按显示密度隐藏)→ 底栏(宫名·宫干支·大限区间)。
命宫加金晕底 `--gold-glow`,身宫加「身」徽,空宫显示「借」字引导线指向对宫。

**显示密度三档**:简洁(主星+四化)/ 专业(+辅星+格局)/ 大师(+杂曜+十二神)。
**三方四正联动**:悬停/选中宫位时,三方四正以 `--gold-dim` 描边,对宫连线渐显。
**运限叠加**:激活时间轴后,流曜以描边(空心)徽章入宫,与本命星(实心)区分;
运限宫名以小字第二行显示在底栏。

## 6. 禁止项(反模板红线)

1. 金紫渐变、彩虹渐变 hero
2. 强调色超过一个(垣紫永不做交互色)
3. emoji 做功能图标(图标一律线性单色,取象于星/仪/卷)
4. 全员 `rounded-lg` 与大阴影卡片堆叠
5. 硬编码色值绕过 token

## 7. 落地方式(P1 契约)

- `web/` 建立后,`tokens.css` 原样进入 `web/src/styles/tokens.css`,
  Tailwind 通过 `@theme` / CSS 变量桥接引用,shadcn/ui 组件全部重着色到 token
- 本文档 + tokens.css 是 Opus 铺页面的验收依据:任何页面出现非 token 色值即打回
