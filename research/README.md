# research/ — 内部研究语料(不对外分发)

本目录存放从用户提供的资料包(nihaisha.rar,1.6GB)提取清洗后的**研究用文本语料**。

## 用途与边界

- **仅供内部研究**:校准排盘引擎口径、丰富 AI 解读知识库、案例反向校验、衍生产品调研。
- **不上架古籍阅读器**、不对终端用户展示全文、不对外分发(用户拍板:「古籍暂时不上传,咱们先研究」)。
- 其中含现代作者著作,版权敏感,严禁进入任何公开构建产物。

## 结构

- `corpus/` — 142 篇清洗后 UTF-8 文本(约 950 万字符),文件名 `<内容hash8>-<规范名>.txt`
- `corpus/manifest.json` — 全量清单:来源路径、格式、字符数、来源目录;
  另记录跳过项(62 个扫描版 PDF 待 OCR、占位存根)与 19 组去重映射
- `books-json/` — 由 `go run ./tools/researchgen` 生成的语料 Book JSON
  (`research: true`),经 `CORPUS_EXTERNAL_DIR` 指向本目录即热加载。
  运行时隔离(有测试钉住):书架/公开检索/直接访问全部不露出,
  仅 AI 解读的内部检索(`SearchAll`)可引用。

## 提取管线(可复现)

原始包 → unrar(UTF-8 locale)→ 按格式提取(md 直读 / docx=python-docx /
doc=catdoc / 文字版 pdf=pdftotext,扫描版以 pdftotext 前 3 页采样判定)→
噪声清洗(页码/水印/广告行)→ 内容指纹去重 → 本目录。
