# 《周易》经文层取材笔记(P39)

## 来源与许可

- 维基文库(zh.wikisource.org)《周易》64 子页,整理之**通行本经文**,公有领域;
  MediaWiki API 逐页抓取 wikitext,OpenCC t2s 转简体。
- 首选方案本为研究语料中的伊川易传(程传含经文),经查该文件系节选
  (588 行、仅 14 卦),不足以抽全谱,遂改走维基文库(与梅花易数全文
  入库同一路径)。抓取脚本存 scratchpad(zhouyi_extract.py),
  产物 `internal/zhouyi/zhouyi.json`。

## 抓取解析要点(踩坑存照)

- 经文行全部位于 `<span style="color:blue">` 内,卦辞行 `'''卦名''':…`,
  爻辞行 `爻题:…`;艮页 span **不闭合**,须按行截取;
- 否/艮爻题用全角**逗号**分隔;履/否/同人/艮为**卦名连文**卦辞
  (履虎尾/否之匪人/同人于野/艮其背),无冒号,取整段保留卦名;
- 坤卦辞分**三段 span**(君子有攸往…/利西南得朋…),爻辞未始前的
  蓝行皆属卦辞,拼接;
- 页面自带「X下Y上」组成行,与手编金文卦序表逐卦互证;
- OpenCC 单字陷阱:繁体链接名「乾」t2s 成「干」、「遯」不转,均加别名;
- 本环境写盘会把全角标点规范化为半角,正则里的全角冒号/括号须用
  `：` 码点转义(断案批量解析器同坑)。

## 校验

- 64 卦齐备,384 爻辞 + 用九/用六 = 386 条;
- 逐卦:爻题序与上下卦爻画逐位一致;页面组成 = 卦序表组成;
