# 扫描版古籍 OCR 试点评估(P8-3)

日期:2026-07-17。目标:评估无文本层 PDF 能否批量 OCR 入研究语料
(仅内部研究用途,不上架、不对外分发)。

## 库存盘点

对 `corpus-raw/` 全量 PDF 做文本层探测(第 8–18 页提取字符数 <100 判为无文本层):
**88 个文件无文本层**,约 2 万页。逐本渲染中间页人工分类:

| 类别 | 代表 | 特征 | OCR 可行性 |
|------|------|------|-----------|
| A 数字排版无文本层 | 黄金策、返本归宗、六壬金针 | 横排简体、干净字体 | 高(见实测) |
| B1 影印竖排繁体 | 中国绝学 1–11 集、滴天髓阐微、陈雪涛紫微系列 | 双页拼扫、边框、噪点 | 中低 |
| B2 明清刊本影印 | 新锓紫微斗数全书(明南阳堂刊本)、家傳心易卦數 | 木刻字、版式古 | 极低 |
| C 现代图解彩页 | 图解周易预测学、图解道教天文历算学 | 图文混排、底色 | 低(版式破碎) |
| D 表格/图谱 | 铁版神数各卷条文表、星官布局图、罗盘图 | 结构化图 | 不适用 |
| E 手写/手稿 | 壬学琐记、南极神数家传秘法手稿、个人笔记 | 手写体 | 不可行 |

## 实测(tesseract 5.3.4,chi_sim/chi_tra/chi_*_vert)

**A 类样本**:《黄金策》第 20 页(3300px 宽数字版)。
`chi_sim --psm 6` 字准约 95%;错误集中于:**「爻」在全部配置下 0 识别**
(系统性误读为 芝/艾,tesseract 训练语料盲区)、休囚→休办、悔吝等术语。
缩放 40/50/70% 与 psm3/6 网格试验:探针短语命中最高 4/6,「爻」恒 0。
结论:需领域后校正表(爻/祿/曜/悔吝等)才可达约 98%。

**B1 类样本**:《中国绝学第 01 集》第 30 页(河洛紫微斗数归元,竖排繁体双页)。
拆半页后 `chi_tra_vert --psm 5 @200dpi` 为最优:正文字准约 88–92%,
但领域词高频错乱(紫微斗數歸元→棕徵半數過元、官祿→官鐘、化曜→化喔)。
反直觉结论:**300dpi 更差**(辣門見山/官匠),二值化更差,
`chi_tra_vert+chi_tra` 组合严重劣化。200dpi 原图即峰值。

## 结论与路线(已定)

1. **不做批量 tesseract 入库**。红线:研究语料会被 SearchAll 逐字引用进
   付费 AI 解读/解卦的「古籍参考」,88–95% 字准的噪声会直接污染付费输出,
   且领域关键词(爻/祿/曜/紫微)恰是错误重灾区。
2. **经典正文优先走文字版**:黄金策全文已被《卜筮正宗》(文字版,已入库)
   逐条注解覆盖;滴天髓/穷通宝鉴/神峰通考为公版,后续可采文字版通行本,
   无需 OCR 影印件。
3. **扫描独有的高价值内容**(中国绝学·河洛紫微归元、铁版神数秘卷、
   陈雪涛紫微系列)留待 LLM API key 到位后,用**多模态模型逐页转写**
   (竖排繁体无碍,预期字准 >99%),按卷分批试点后入研究语料。
4. tesseract 环境与参数保留为工具(粗检索定位、人工查阅辅助):
   `pdftoppm -r 200` → 竖排繁体拆半页 `chi_tra_vert --psm 5`;
   数字版 `chi_sim --psm 6`。不作为语料生产管线。

## 复现命令

```bash
apt-get install -y tesseract-ocr tesseract-ocr-chi-{sim,tra} tesseract-ocr-chi-{sim,tra}-vert
pdftoppm -png -r 200 -f 30 -l 30 book.pdf page       # 渲染
# 双页拼扫先按宽度对半裁切,再:
tesseract page-030-R.png out -l chi_tra_vert --psm 5  # 竖排繁体
tesseract page-020.png   out -l chi_sim      --psm 6  # 横排简体数字版
```
