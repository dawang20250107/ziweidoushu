## 二、起课体系骨架(自理法易简摘录)

1. **天地盘**:月将加占时。换将按**中气**:「雨水始至春分前一天用亥将,
   春分始至谷雨前一天用戌将……」(逐中气退一支)。lunar-go 有节气
   能力,工程可直接支撑。
2. **四课**:日干寄宫(干寄宫表)与日支,各取本位及上神成四课。
3. **三传(九宗门)**:「贼克、比用、涉害、遥克、昴星、别责、八专、
   伏吟、返吟」**严格按序**;要点摘录:
   - 贼克/比用/涉害/昴星的发用皆取**天盘支**;
   - 「课中有下贼上,无论有多少上克下都要放弃,只取下贼上」;
   - 比用取与日干**同阴阳**之支发用;涉害论深浅;
   - 书中自带完整走例(如「三传申亥寅」涉害课),可直接作黄金用例。
4. **天将**:贵人昼夜诀(「甲戊庚牛羊」等,昼夜贵有别),依贵人落宫
   定顺逆布十二天将。

## 三、工程评估

复杂度高于六爻(节气换将 + 寄宫 + 九门分支 + 涉害深浅比较 + 昼夜贵
判定),但每步皆确定性可表;无历法之外的新依赖。风险点:涉害深浅与
别责/八专等冷门课的口径分歧,须跨书互证(理法易简 ↔ 64 课经 ↔ 壬归)。

## 四、实施路径(复制六爻已验证的方法论)

1. 核心表定式测试:月将(中气表)/干寄宫/贵人昼夜/十二天将序;
2. 九宗门逐门黄金课例(理法易简走例逐个钉死);
3. 《64 课经》课型全谱定表回归(对应六爻 TestBaGongTable);
4. 断案课例批量回归(待扫描转写,对应 liuyaoverify 377 例);
5. 产品端作问卦第三占法接入(仪式/盘面/AI 解课),UI 后置。

## 五、第一步已实现(internal/daliuren)

天地盘 + 寄宫四课 + 九宗门三传全部落地,以理法易简走例钉死:

- **月将**:中气表(雨水亥将起,逐中气退一支)——语料完整逐字抄录;
- **寄宫**:甲寅乙辰丙戊巳丁己未庚申辛戌壬亥癸丑(起课定式);
- **天地盘**:月将加占时,`tp[i]=(将+(i-时))%12`;
- **九宗门**(按理法易简**简化口径**,非实际涉害深浅):
  - 贼克(单克,第一课以**日干本气五行**论克,断案案02 钉死)/
    比用(多克取阴阳同日干之上神)/涉害(俱比于比者中取,**孟>仲>季>课序**,
    孟仲季论上神所临**地盘位**——「先取孟上神」之见机式,断案案76 钉死);
  - 遥克(四课无克,干与上神相克)/昴星(无克无遥,阳日酉上刚仰、阴日
    酉下柔俯,末归干/支);
  - 伏吟(将=时,有克取克无克刚干柔支,中末用刑;**初传自刑者阳日中取
    支上、阴日中取干上**,复自刑冲取末传——断案案215 钉死)/
    返吟(将冲时,无克取**驿马**,中支上末干上);
  - 遥克**先取克干者(蒿矢)**后取干克者(弹射)——断案案36/95 钉死;
  - 八专(干支同位无克不论遥克,刚日干上顺数三、柔日四课上神逆数三,
    中末并干上)/别责(无克无遥三课备,刚日干合寄宫上神、柔日支三合
    前一辰,中末并干上)——课经集走例钉死;
  - **重课规则**:派生课(二/四课)与前课下上全同者不取其克(案07),
    干支两正课不在此限(案220 癸丑日「俱有克」);
  - 中末通式:中=初传之上神、末=中传之上神(顺天盘)——golden 例验证。

**黄金基准**:甲日戌时丑将 → 四课「寅巳/巳申/午酉/酉子」→ 二重下贼上
比用取申 → 三传申亥寅(TestLiFaYiJianExample),连同月将/寄宫/伏吟/
返吟定式测试全绿。

### 全域冒烟(TestCastFullDomain)

10干×12支×12时×12将=**17280 课**全部起课不崩;断言四课上神=天盘对应、
三传合法、伏吟(将=时)/返吟(将冲时)与天地盘精确自洽。课体分布
(九门齐备口径):贼克 7740 / 涉害 2160 / 比用 1992 / 遥克 1512 /
伏吟 1440 / 返吟 1440 / 八专 348 / 别责 336 / 昴星 312。
量级与古人「贼克最多、涉害次之」的经验相合。

### 《六壬断案》全书扩批回归(TestDuanAnBatchRegression)

解析器自动从全书 228 个案块提取「日干支/占时/月将/书载三传」
(压平断行、识别空亡传「空X」记法、书头空亡与日辰互证护栏),
**208 例可机验、205 例吻合、3 例存疑、0 例不符**。以例校机共钉死七条口径:

1. 第一课克战以日干本气五行论(案02);
2. 涉害孟仲季按上神所临地盘位、俱比于比者中取(案74/76/188/189/191 五例;
   曾试历位数克深浅法,与诸案不合而弃——「不数深浅先取孟上神」实证成立);
3. 遥克先取克干者(蒿矢,案36/95);
4. 伏吟初传自刑者,中传阳日取支上、阴日取干上(案215);
5. 派生课重前课者不取其克(案07),干支正课不在此限(案220);
6. 别责/八专发用(课经集走例 + 断案 137 独足格盘面);
7. 旬空两支与书头「XY空亡」逐例互证(纯算术,兼作日辰误提护栏)。

3 例存疑(120/137/208)均系原书传抄讹误——遁干与旬不合、将时倒置、
占时讹字——且盘面四课反推均证引擎复现为正,存疑表内逐例注明证据。
